# SDO COLLECTIONS Website

A responsive showcase website for SDO Collections, a home textiles and bedroom accessories brand.

## Included
- `index.html` — website content and sections
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/sdo-collections-logo.png` — generated SDO Collections logo artwork

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `sdo-collections`.
2. Extract this ZIP file on your computer.
3. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder to the repository's root (not inside another nested folder).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes. GitHub Pages will show your website address on the Pages settings screen.

## Before sharing publicly
- Replace the sample bedroom/product photographs with your own product photographs when available.
- Confirm the product categories and contact numbers.
- The design loads Google Fonts and sample photographs from external image URLs, so those parts require an internet connection.
